## Лекция 3: список задач

Программа работает в бесконечном цикле и принимает команды:
- `help` - список команд
- `profile` - имя, фамилия и год рождения пользователя
- `add "текст"` - добавить задачу
- `view` - показать все задачи
- `exit` - завершить программу

Задачи хранятся в массиве `todos` (начальная длина 2). Когда место
заканчивается, создаётся новый массив в 2 раза длиннее, и задачи
копируются в него.
